### ✍️ How to Add a New Job Competency
1. Click the **Add file** button at the top right of this page and choose **Create new file**.
2. Name your file inside the `competencies/` folder (e.g., `competencies/devops-engineer.md`).
3. Copy and paste the standard Markdown template.
4. Click **Commit changes...** to save your work.
