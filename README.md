### 🛠️ How to Contribute Competency Changes (Web UI Guide)

All updates must be made against our `development` branch via a fork. Please follow these steps completely inside your browser:

1. **Fork the Repository:** Click the **Fork** button at the top-right corner of this page to create a copy of this repository under your personal GitHub profile.
2. **Ensure correct branch:** In your personal fork, make sure the branch dropdown in the top-left is set to `development`.
3. **Make Your Changes:** Navigate into the `competencies/` folder, edit an existing `.md` file or create a new one using **Add file** ➔ **Create new file**, and commit your changes to your fork's `development` branch.
4. **Open a Pull Request:** Go to the **Pull requests** tab of your fork, click **New pull request**, and set the targets exactly like this:
   * **Base repository:** `Your-Organization-Name/subsector-software-development` @ **`development`**
   * **Head repository:** `your-username/subsector-software-development` @ **`development`**
5. **Submit:** Click **Create pull request** and fill out the details describing your competency updates.
